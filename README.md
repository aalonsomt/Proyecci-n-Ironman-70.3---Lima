# Proyección Ironman 70.3 Lima 2027 🏊‍♂️ 🚴‍♂️ 🏃‍♂️

**Proyecto personal de Data Analytics**  
Estoy preparándome para mi primer Ironman 70.3 Lima en 2027.  
Este proyecto consolida y analiza los resultados históricos del evento para generar benchmarks, percentiles y proyecciones de rendimiento.

## 🎯 Objetivo

Centralizar, limpiar y analizar los resultados históricos del **Ironman 70.3 Lima** (2023-2026) para:
- Facilitar la consulta y comparación de atletas
- Generar métricas de rendimiento y percentiles por categoría
- Crear un dashboard interactivo
- Proyectar mi propio rendimiento para 2027

## ✨ Características principales

- Consolidación de resultados históricos (4 ediciones)
- Limpieza y estandarización de datos
- Cálculo de métricas clave y **percentiles**
- Análisis por categoría, país, género y evolución temporal
- Dashboard interactivo en Power BI
- Proyección personal para 2027

## 🛠️ Tecnologías

- **Python** (Pandas, NumPy)
- **Jupyter Notebooks**
- **Power BI**
- **Git & GitHub**
